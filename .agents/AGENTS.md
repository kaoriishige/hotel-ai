# 10施設AI統合ポータル 厳格システム保護 ＆ 全施設横展開自動ローカライズルール (AGENTS.md)

本ファイルに記載されたルールは、本リポジトリで作業するすべてのAIエージェントが **例外なく最優先で遵守すべき絶対ルール** です。

---

## 🚨 1. 全施設横展開（機能展開）時の自動ローカライズ・他施設破壊防止ルール 【最重要】
- **どの施設（例：那須ユートピア美野沢、赤沢温泉旅館、箱根、熱海、京都等のいずれの施設起点であっても）で新規開発・修正した機能や画面を「全施設に導入・適用」する際、起点となった元施設のテキストやファクトをそのまま他施設へコピペ・上書きすることを永久禁止とする。**
- **機能やシステム構造のみを全施設へ横展開し、テキスト・RAG・施設概要・競合ホテル・食事・設備情報は、必ず展開先の各施設専用のファクト・テナント設定（`tenants/<tenantId>/`）に合わせて自動的にローカライズ・適応させて生成・デプロイすること。**
- 一つの施設で構築した機能を全施設へ導入する指示があった場合でも、**他の施設が元施設の内容（例：サウナ/ぬる湯/看板猫/BBQ/地域独自の競合データ等）に誤って書き換わる事故を絶対に発生させてはならない。**

## 🚫 3. 遠藤正俊オーナー個人動画＆SNSシステム（`endo-sns`）の独立保護ルール
- `endo-sns`（オーナーショート動画投稿管理）は、**遠藤正俊オーナー個人の人生哲学・生き方・思考法・マインドセット**のみを発信するシステムである。
- 旅館のPR、宣伝、料理、温泉、館内案内、客室等の言葉は**一切入れてはならない**。
- 投稿テーマは以下の【遠藤正俊個人の生き方・思考法テーマ】を厳守すること：
  1. 安定を捨てて、50代で自分の生き方に舵を切った決断と思考法
  2. 「他人の価値観」で生きるのをやめ、人生の軸を取り戻す技術
  3. 世界中で大自然を見て気づいた、現代人が疲弊していく本当の原因
  4. なぜ価格競争や数字の比較に巻き込まれると不幸になるのか？
  5. 「何もしない時間」を意図的に作れない現代人が余白を取り戻す方法
